# HUZEE OS Website

Responsive English landing page for the HUZEE OS project. Built with plain HTML, CSS and JavaScript. No framework, build step, backend or paid hosting required.

## Preview
Extract the ZIP and open `index.html` in a modern browser. Optional local server: run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public repository** named `huzee-os-website`.
2. You can leave the repository empty at creation.
3. In the repository choose **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, `script.js` and `README.md` directly into the repository root.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then click **Save**.
9. After publishing, GitHub Pages displays your public URL. It will look like `https://YOUR-USERNAME.github.io/huzee-os-website/`.

## Updating
Edit a file, upload the replacement to the same repository and commit. GitHub Pages publishes the update automatically.
